# 阅读入口与字幕关键词检索

[从作品进入](../reading/index.md) · [官方项目与本批资料](../reading/projects.md) · [公开字幕](../reading/captions.md) · [完整资料目录](../INDEX.md)

## 先读项目，再查来源

项目页先显示阅读摘要、已有的A/B站来源、可打开的字幕和事件列表。目录日期标明依据；作品年代不代替某次事件的日期。文件编号、格式、MB、解码与发布状态保存在折叠的完整记录中，原编号与关系不改。

《玻璃动物园》页的读本讨论样例来自已公开的`P4-S000946` cue 1–8，以机器字幕作为阅读依据；没有据此补写说话者身份或事件日期。编辑说明保存在`content/reading-notes.json`，生成器检查它只能指向该项目已经公开的字幕及实际存在的cue。

原语、English、中英是同一来源的不同字幕版本；原语记录仍保留`language=und`，不因为页面使用中文就把未知语言改成中文。同一份文字可以对应另一文件版本，字幕相同不等于录像字节相同或事件相同。

[既有 YouTube 视频](../publications/README.md)单列平台元数据关联。频道、可见性和描述源哈希的回读，与完整播放、在线字幕核验分别记录；关联记录不替代播放或字幕检查，也不证明每条视频的项目内容归属。

## 在本地检索

只需要Python标准库。在仓库根目录执行：

```sh
python -X utf8 scripts/public_reading.py search --root . --query "剧本" --limit 20
python -X utf8 scripts/public_reading.py search --root . "排练" --language original
python -X utf8 scripts/public_reading.py search --root . "rehearsal" --language en
```

关键词支持中文和英语，大小写与全半角先统一；空格分开的关键词须同时出现在同一cue中。`--query`与位置参数两种写法任选一种，不能同时填写。`--limit`为1–100，默认20。

`--language original`按原语字幕角色筛选；也可使用记录里的`und`、`en`或`zh-en`。不传语言时检索所有公开版本，同一段文字在不同的字幕或文件记录中可能分别返回。

结果JSON包括：

- 项目ID、展示编号与名称。
- 实际来源的asset/file ID与展示编号、关联事件ID。
- subtitle ID、展示编号、字节SHA-256、语言与角色。
- cue编号、`source_zero`、起止毫秒与时间码、该cue原文。
- 机器稿与听校状态，以及绑定版本路径的GitHub原文URL和行号。
- 官方档案与研究依据的原文URL，以及所对应原始文件的完整SHA-256。

结果指向的源文件保持原有对应。仅通过`equivalent_public_export_subtitle_id`关联到另一字幕的记录不会独立加入检索。已登记的字节副本保留文件关系文字，公开字幕入口仍只属于获批来源；另一编码候选保留自己的文件关系。复制字幕路径或相同字幕哈希都不能绕过来源白名单。

## 检索的范围

`reading/manifest.json`只保存小份来源与版本清单，不保存字幕全文或本机路径。当前可读数量由该清单生成，不沿用旧批次数量。

生成与检索都要求`.p4-public-scope.json`明确批准字幕ID及`allowed_caption_versions`中的版本SHA-256。相同ID换了字节也需要新批准；没有白名单的`public_export`、等价字幕引用和已撤下的SRT不能重新进入阅读入口。目录中经范围排除的身份同样被拒绝。

获批条目还必须为机器稿、`source_zero`，并通过官方来源、公开范围和原文字节三层核对：源asset/file与官方证据绑定，原始文件完整SHA与`evidence/`中的官方逐项证据一致；`public_export`标为`approved_official_source_and_text_scope`；版本路径、声明SHA与实际SRT字节一致。官方网页快照的SHA与原始影片SHA分别保存，不混用。详见[公开范围投影](公开范围投影.md)。

检索先核对清单是否仍与目录、公开范围及官方证据一致，再按所选语言读取这些SRT并核对哈希。`captions/`出现清单以外的SRT也会阻止生成与检索。没有公开导出的转写、私有原文和仅有等价字幕映射的副本不会被读取。它不联网、不上传资料、不调用模型，也不重新识别原片。

## 生成与检查

```sh
python -X utf8 scripts/public_reading.py build --root .
python -X utf8 scripts/public_reading.py check --root .
python -X utf8 -m unittest discover -s tests -p test_reading.py -v
```

`build`先验证输入和全部公开SRT，再更新自己负责的INDEX、项目页与`reading/`文件。`check`只比较这些生成文件的预期字节，不修复、不重写README或其他协作者的文件；漂移或无效公开字幕会返回非零状态。

代码与生成的JSON/Markdown使用UTF-8/LF，公开SRT的原始字节保持不变。生成内容没有当前时间、本机绝对路径或运行时Git HEAD；相同输入反复生成没有差异。导读修改、公开导出增补、项目对照与目录更新后，应统一重新生成，不能只手改某个项目页。

模块接口为`build(root)`、`check(root)`和`search(root, query, limit=20, language=None)`。前两者返回摘要dict，`check`包含`ok/errors`；`search`返回带来源的结果list。目录导入的统一生成钩子由`archive_catalog.render_indexes`接入本模块。
