## Research narrative: evidence limits below

The retained machine notes of pre-performance preparation call for a complete run with technical cues following, allowing faster speech so that technical coordination can be checked first. The research distinction is between checking light, music, projection and transitions, and setting the pace of a performance. A separate request to slow the performance may serve a different purpose. A requested complete run is not proof of smooth completion; notes about a remote control and the main light preserve unresolved coordination. The meaning of “first combined run” remains to be clarified.
