                           风景再造


                          description
在对摄影图片的处理中我再造了新的图片的排列并置的方式。在这里图像的属性被消解与再造和重新赋值，而当再次走入宏观与微
观的视角中去，新与旧的属性又有产生了新的融合，自然地又突然冒了出来。 而图像的再造与原本的拍摄的本体自然来说又再一
次完美对接重合在了一起，天与地分离在交融之间，一个似曾相识的幻象相对于直接的记录来说，又激活了一个新的世界。摄影是
一张张真实世界的切片，却永远无法包含全部的整体使其真正成为客观，而它们的重组——在一种客观规则下，对整体的描述更充
                        满不期而遇的巧合。
                            media


                           reflection
我一直都在想尝试发明或发现新的可能性能将图片以更加完美的展现。在这个信息爆炸的时代，图片已经远不止是之前的意义了，
大量的照片充斥在人们的生活之中，但恰恰相反，越多的堆砌反而越是一种消解，被排列一堆的时候正是被完全的消解的时刻，而
       整体也不再存在。我的思考也就建构在局部与整体的关系之上，让其和谐与统一变为自然而然的形式

                            十二水灯


                           description
作品是对于中国古代南宋画家马远的《十二水图》重新诠释，并将其实现为3d的立体雕塑。我运用数学公式将数值赋予到每一个点
之上，而不是用传统的建模方式去运用鼠标去对点或是面的推拉去进行构造。当最终的数字模型生成后，再进一步增加体量与厚度
，消除三角破面，最后生成可用于3d打印的文件。当实物被打印出来后，在进行更进一步的控制与调整，将部件再次组合调试成最
                          理想的模式。


                            media


                           reflection
在项目中，从最早的概念出发到最后的作品形成，是一个漫长的周期。但不可思议的是在每一个环节中都充满了惊喜与意料之外的
  可能性，每一次的决定，每一次的探索都是值得的，因为没有任何他人的经验可以被借鉴，而每一次的解决就是一次创新。

                            哈姆雷特的镜子


                               description
在这一个个短小的视频中，是我对莎士比亚的《哈姆雷特》的再次演绎和诠释。我肢解了整个戏，变成了一些似是而非的片段，你
当然可以说这跟哈姆雷特毫无关系，这只是我对其的理解，毕竟一千个人读，就有一千个哈姆雷特。延宕在他者时空中的哈姆雷特
不断地变化着角色，在混乱的里与外的屏幕之间是无法准确定义的人物。在不断地投射反射，或是遮挡掩藏下，模糊或是消失的属
性又似乎再次出现，而我成为这一个个片段中的角色，与其一起癫狂或是哀伤。在虚无的真实之中去寻找存在的意义，To be or not
                        to be, this is a question.


                               media


                          reflection
大屏幕与投影与演员三者构成了一种关系，在这里，影像被投射在屏幕或是人物身上，而人与屏幕的信息交流与交互却都来源于其
自身的表演之中。时间是混乱或是错置的，空间更是陷入在屏幕之中的。在项目中，屏幕作为人获知世界的窗口，而投射的本属于
        自己的虚像又再次成为了对于主体本身的欺骗，而这也是我对新媒介所做的新的探索和尝试。
