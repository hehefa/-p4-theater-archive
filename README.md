# P4 剧场档案 / P4 Theater Archive

这里持续整理 P4 的项目、排练、演出、讨论与相关实践：每件材料有稳定编号，每次事件有来源线索，视频、字幕和后续修订可以相互找到。

**从 [档案总目录](INDEX.md) 开始浏览。** 查某个项目时，进入对应的项目页；补充或纠正材料时，按 [增补指南](CONTRIBUTING.md) 操作。

## 这次建档收录了什么

首轮盘点于 2026 年 10 月 26 日完成，登记了 **18 个候选资料集合、1,740 个物理视频文件，约 3.50 TB**。资料集合不等于已确认的独立项目，同一项目可能分散在不同集合里，一个集合也可能混有多个项目。数量包含待甄别副本、修复版本和空文件，不代表有 1,740 条可直接发布的视频。

本版先公开目录结构、编号、文件与字幕状态。原片和未经公开审核的字幕正文没有随目录自动公开；视频是否上传、字幕是否听校、内容是否适合公开，分别记录。

当前机器汇总见 [目录状态](catalog/summary.json)。汇总区分人工申报记录与平台已核验上传：手工登记的视频 ID、可见性或播放情况仍是人工陈述，不自动成为平台回读证据。这些数量均不能用来推断整个 YouTube 频道的视频总数。

| 材料 | 这里保存什么 | 目前应如何理解 |
| --- | --- | --- |
| 项目与事件 | 项目名、事件关系、日期线索、分类与来源 | 未确认的归属和日期保留待核实状态 |
| 视频 | 档案编号、版本关系、大小、校验状态、发布记录 | 文件登记、完整解码与实际观看是不同步骤 |
| 字幕 | 对应视频、语言、版本、校验及审核状态；通过公开审核后可加入正文 | 机器生成不等于逐句听校，字幕存在不等于已经上传到 YouTube |
| YouTube | 人工申报的视频 ID、频道、链接、可见性，以及单独的核验状态 | 当前登记命令只保存人工声明；平台播放、字幕与可见性仍须实际回读确认 |
| 后续实践与研究 | 可公开的事件说明、证据定位、修订记录 | 推断与事实分开，私人笔记不自动导入 |

可读的项目页和机器可读的 `catalog/` 使用同一套记录。同一路径的增量导入沿用已分配编号；补全标题不改编号。已建档文件移动或改名时，须先登记并迁移私有路径键，当前导入器不会自动识别这种移动；未迁移就导入会生成候选新记录。旧系统已有的标识保留并建立对照，新展示编号不会替换旧的身份标识。

## 如何判断一项材料是否已经完成

查看条目的具体状态，而不是只看有没有文件。至少要分别确认：内容归属、文件可读与完整性、字幕质量、公开范围，以及线上视频与字幕的实际状态。未完成的步骤会保留为待核验，不用一个“完成”覆盖所有环节。

全量新计算 SHA-256、全程音视频解码、逐条人工观看与听校尚不能由本次目录盘点替代。修复版与原版单独登记；字节完全相同也只说明文件相同，不自动证明它们属于同一个事件。

## 使用与权利

公开可访问不代表所有材料采用统一的开放许可。视频、声音、字幕、文档和第三方参考资料的权利状态按条目记录；尚未确认的保持未知。引用时请同时写出档案编号、条目标题、版本与来源链接。转载、改编或再发布前，应核对对应条目的权利与公开范围。

这个仓库负责可追踪的目录和文本版本。**原始视频还需要独立备份；YouTube 播放副本和 GitHub 目录都不能替代原片。** 保存方法见 [保存与恢复](docs/保存与恢复.md)。
