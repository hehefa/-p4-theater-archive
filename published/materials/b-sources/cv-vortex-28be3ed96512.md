《漩涡》

一、本来逻辑：
1. 背景：由于生育率下降，人口老龄化，发生了人口危机，为拯救人类危局，颁布了新的
泛绿，凡是三十天内没有找到伴侣的人，将会被回炉重造。
2. 主线剧情：
阿斌分手后的自白 → 阿斌和 Kara 约会失败 → 阿斌失败自白与梦境 → 阿斌与乞丐配对
失败 → 阿斌自白、警察踢打和最后的希望 → 阿斌和萨利的成功 → 主持人的末日审判

二、我以为的不足：
1. 既然年轻人可以被重造，这一技术完全可以解决人口老龄化的问题，人老了重开，老年
人变婴儿，问题不存在
2. 最后一幕感觉有点乱，这个规则不是本来就存在的吗，为什么这三个人和主持人要循环
一遍呢?
3. 梦境也很奇怪，而且和龙虾里的场景相似，建议替换成另外的方式。

三、我想要做的：
1. 让这个剧本能够打到我们，拳拳到肉，而不是囿于荒谬的风格导向而对着虚空挥拳，所
以起码保证在剧情背景达到可理解的荒谬程度与人物行为逻辑的可理解；
2. 在剧本中仍然保留设置一个较为荒谬的背景，但是更多地探讨被卷入这样的背景后，我
们怎样被迫去思考“爱情” 、“婚姻”和“生育”，而不想看一个被摆布的“国男”形象被团
团包围，那样的人物是死的，是为了写作而被写出来的；
3. 所以在此基础上，我们也可以从女性视角以及更多的视角去探讨这一问题。
4. 关键在于表现在被规则的漩涡卷入之后，我们的爱情观的被冲击和开环的思考。

四、我尝试填补的核心逻辑：
1. 人口老龄化，对经济有重大影响，国民生产总值蹒跚而行，无价值人口暴涨，社会运转
的基础力量不足；政府公共财政（医疗卫生）开支压力加剧，社会安全保障系统遭遇问题，
老龄化加剧，老人作为社会中的弱势群体难获保障。
2. 爱情多美丽呀，人人都愿意追寻，而生殖繁衍是爱情最自然的果实，让我们诱导爱情吧，
为了社会为了人类。
3. 这场大型真人秀，便是政府以此上逻辑运作的结果，为了减缓人口老龄化的各种弊病，
而爱情是虚伪的噱头。
4. 大型社会真人秀的规则：可报名参加，并且有大量男女报名参加，为了爱情的噱头，签
下爱情合同——三十岁以下的男女可报名（女性 28 岁，男性 30 岁），这里的每个人都渴求
爱情（加大渲染）。并且如果在满三十岁之前结婚后，会获得真人秀节目的奖赏，比如购房
补贴等等，但前提是不能离婚，并且鼓励生育。但如果失败了，或者之后违约了，将会有惩
罚，统统被判处终生单身，并且每周为养老院、老年人社区“志愿”服务五天。
  于是无数青年汹涌而至，因为爱情呵，爱情莫不就是那最美丽的人生意义吗。
  这是故事的背景设定。
