# P4与何发：已完成的公开文字资料

[字幕下载](captions.md) · [文稿与研究](materials.md) · [逐项来源与版本](manifest.json)

本批补入310份字幕、113条官方材料、64条研究。字幕按准确YouTube发行版和语言归类；文稿保持既有署名、公开范围与原文链接。何发个人作品保留个人归属，未并作P4剧目。

官网已公开版本经过本次HTTP回读与文件哈希核对。75条文字材料有原站MD/TXT字节副本；38条影音材料保存公开说明及观看／下载链接，不把大体积媒体搬入Git。Fa re-review三份完整机器稿和《两双拖鞋》两份剪辑版字幕另有来源、时间轴和版本校验。

这批发行版使用原有官网材料ID和YouTube ID，不分配新的P4原片编号。原片投影的3份白名单SRT与295项范围排除规则保留；已撤下的96份字幕没有恢复。一条只有片头片尾署名、没有实质项目背景的占位字幕未作为完整转录发布。

字幕保留机器稿或原有发行状态，不宣称新增人工逐句听校。本次发布目标为GitHub；平台字幕历史记录、此次官网回读和YouTube实际字幕上线分别记录。[原片目录](../INDEX.md)的数量不包含这些发行版。

检查与检索：

```sh
python -X utf8 scripts/official_publications.py check --root .
python -X utf8 scripts/official_publications.py search "剧本" --root .
```

检索结果带字幕版本、cue、该发行版的时间码和原文链接。公开访问不授予统一开放许可；权利与署名沿用原资料。
