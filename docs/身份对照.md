# 一套身份，多处引用

[机器可读身份对照](../registry/identity-crosswalk.json)从`catalog/projects.json`生成，供Mac、PC及既有工具快速读取已存在的对应关系。

- `catalogue_id`和`accession`原样保留，不新分配编号。
- 既有外部ID必须带namespace，保留原来的`mapping_basis`；同名候选继续是候选。
- 官方项目页、B站相关研究页作为已有项目级引用导出，不表示该项目下每个视频都已经确认归属。
- 旧别名原样保留，不按名称或编号格式擅自替换canonical ID。
- 私有路径、内部笔记和原始输入不在这个投影中。

更新生成源后执行：

```sh
python -X utf8 scripts/export_identity_crosswalk.py --root .
python -X utf8 scripts/export_identity_crosswalk.py --root . --check
```

一个外部namespace/ID如果被两个不同本仓实体认领，导出会失败，保留问题供对照，不自动合并。不同文件的同字节关系和不同事件身份仍分别记录。

接素材工作台或Archive Toolkit时，把本仓ID作为另一个namespace的外部ID，另存有依据的对照；不把本表的项目级对应当成源文件或公开视频版本已经匹配。
