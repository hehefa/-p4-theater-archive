## 公开正文

第3页将2019年前身《斗兽场》的发起归沈博伦，将2021年再创作归紫色行动艺术小组；第4页讨论会议与投票方法，第7至8页连接档案、再创作与传播，第16至18页分列沈博伦、何发、邵逸凡。
