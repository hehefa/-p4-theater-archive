# 何发论格雷伯

会议已经长到楼下

桌子第一次变长时，没人注意。

2014年，伦敦。我借会议室讨论拍片，格雷伯坐在另一头。我说再加一项设备分工，桌面咔地接出一截，他连人带椅往后滑了半米。他把杯子拿稳，问我还剩几项。

我说不多，就三项。

桌子连响三声，撞开房门。

有人提议先讨论为什么会这样，走廊里立即多出一张桌面。我去追格雷伯，他已经到了楼梯口。笔记本在桌上滑行，我们只能一边走一边开会。每补一个问题，桌子就继续往前长。

楼下的人问我们要去哪儿。我说不知道，得商量。木头拐了一个弯，把我带到门外。伦敦的风吹散了议程，格雷伯伸手抓住一张，发现纸的边缘已经烤黄了。

他掰下一小角，尝了尝。

“饼干。”他说。

我说这是打印纸。他又掰下一块，递给我。确实是饼干，有点咸，混着打印机的热味。他把“场地确认”那一项吃掉，桌子马上缩回一节。远处有人摔了个趔趄，终于追上自己的椅子。

我立刻宣布，我们应该组织一个吃掉议程的小组。

桌子又长了。

格雷伯瞪了我一眼，把剩下半页塞给我，自己去拿会议室那袋一直没开封的面包。我们沿着长桌分食，没人再讨论谁负责吃。有人把预算撕成两份，问我够不够。我点头。有人挑掉一项明显焦了的“后续工作”，塞给旁边愿意试试的人。

吃到最后，只剩一行“其他事项”。大家都不愿碰，怕里面还包着别的议程。格雷伯将它卷进面包，咬下去，桌子轰隆隆收回楼里。我们端着碗跟着跑，格雷伯一边跑一边护住嘴，怕把“其他事项”咳出来。

最后一截桌子没肯回去，顶开我的剧场后台门，停在洗碗池旁边。我摸出红票根放上去，确认自己回来了。

格雷伯从门那头伸进一只手，递来最后一个空碗。我正要问谁洗，他指了指桌沿。我闭嘴，把水龙头拧开。

格雷伯2013年加入伦敦政治经济学院，这一时期公开讨论民主实践与组织问题。
