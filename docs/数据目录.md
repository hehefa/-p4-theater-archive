# 数据目录与维护命令

仓库使用 UTF-8 文本。`catalog/` 是机器可读的目录，`INDEX.md` 和项目页面用于浏览。每个实体清单采用 `{ "schema_version": ..., "items": [...] }` 外层结构；具体字段以 [目录模式](../schemas/catalog.schema.json) 和当前数据为准。

| 文件 | 内容 |
| --- | --- |
| [projects.json](../catalog/projects.json) | 项目记录与旧标识对照状态 |
| [collections.json](../catalog/collections.json) | 接收或扫描的资料集合 |
| [events.json](../catalog/events.json) | 事件、候选日期及关联 |
| [assets.json](../catalog/assets.json) | 档案材料及项目、事件关联 |
| [files.json](../catalog/files.json) | 物理视频文件、版本与核验状态 |
| [subtitles.json](../catalog/subtitles.json) | 字幕元数据、语言、哈希与质量状态 |
| [publications.json](../catalog/publications.json) | 人工声明与有明确范围的 Studio 元数据回读；播放和线上字幕另有状态 |
| [checksums.json](../catalog/checksums.json) | 已有校验记录与来源 |
| [byte-equality-groups.json](../catalog/byte-equality-groups.json) | 哈希相同的字节内容分组；不自动合并事件 |
| [summary.json](../catalog/summary.json) | 当前导入汇总与范围说明 |

## 增量导入

导入使用本地盘点文件、质量记录和私有登记状态，输出到公开仓库之外的**私有主目录**。当前公开树有强制范围标记，直接导入会被拒绝。占位符替换成维护者自己的路径，不把这些路径写进公开记录：

```text
python -X utf8 scripts/archive_catalog.py import --audit <盘点JSON> --quality <质量JSON> --crosswalk <旧标识对照JSON> --local-state <仓库外私有状态目录> --output <私有主目录>
```

没有已确认的旧标识对照时，省略 `--crosswalk`，保留待对齐状态。再次导入使用同一个 `--local-state`，延续编号与映射；随后执行 [公开范围投影](公开范围投影.md)，不能直接把完整主目录复制到公开库。后台核验运行时不要并发刷新它正在写入的缓存。

## 验证目录

```text
python -X utf8 scripts/archive_catalog.py validate --root <本仓库目录>
```

检查通过表示目录满足该版本检查器覆盖的结构与公开导出约束。它不等于完成全片解码、人工观看、字幕听校或线上发布核验。遇到失败时先读具体报告，修正数据或来源后重跑，不为通过检查而删除未知状态。

## 生成并运行校验计划

```text
python -X utf8 scripts/archive_catalog.py hash-plan --root <本仓库目录> --local-state <仓库外私有状态目录>
python -X utf8 scripts/checksums.py --local-state <仓库外私有状态目录> --limit 10
```

按批次完成后，检查校验结果与失败项，再使用原来的参数重跑 `import` 更新公开目录。`--limit 10` 只是一个小批次数量示例，不说明全库校验已经完成。私有日志与原片位置始终保留在仓库之外。

## 登记平台发布的人工声明

`record-publication` 只保存维护者提供的信息，不上传视频，也不调用 YouTube 核验视频是否存在、归属哪个频道或是否可播放。目标频道固定为 P4 档案频道 `UCp_LyzepcrZX6Cgzv2Qit4w`；该参数的检查不等于已经从平台确认视频的频道归属。

```text
python -X utf8 scripts/archive_catalog.py record-publication --root <本仓库目录> --local-state <仓库外私有状态目录> --asset <视频档案编号> --channel UCp_LyzepcrZX6Cgzv2Qit4w --video <实际视频ID> --visibility <报告的可见性> --reported-at <带时区的ISO时间>
```

记录始终标为 `record_basis=operator_reported`、`platform_readback_verification=not_recorded`。可选的播放和字幕状态也只表达人工报告，不能填成 `verified`。报告字幕已上传或可见时，还须用 `--subtitle` 明确引用已关联到该视频的字幕版本。登记不会改变素材的公开范围、内容审阅或权利状态，也不会解除原有 hold。

汇总中的 `publication_reports_recorded` 只计人工声明，不计 Studio 回读。人工登记命令不能覆盖已有平台回读记录，也不会改变内容审阅、权利或保留状态。

## 录入既有视频的 Studio 元数据回读

`scripts/merge_youtube_receipts.py` 接收另行保存在私有状态中的实际回读收据。它不操作浏览器：操作者须先在正确频道实际读取视频 ID、可见性与描述中的完整源 SHA-256，再保存来源和核验范围；程序核对收据、既有完整哈希证据、本地文件指纹与当前目录。

```sh
python -X utf8 scripts/merge_youtube_receipts.py --root <本仓库目录> --local-state <仓库外私有状态目录> --receipts <私有Studio回读收据JSON>
```

既有视频的 `metadata_only` 证据不能据此声明全片播放、线上字幕或本轮新增上传完成。另一类同视频字幕操作收据单独记录 Studio 发布、观看端菜单可选及实际渲染抽样；当前是 3 新轨发布、旧轨保留和新中文 00:12 单点渲染，英文／双语及完整时段抽样未完成。源哈希映射不是对 YouTube 转码流做哈希。若材料未保留精确观测时间，`platform_observed_at` 保持空值，记录时间不能代替它。

| 汇总字段 | 含义 |
| --- | --- |
| `publication_associations_recorded` | 全部发布记录，包括人工声明 |
| `platform_metadata_associations_verified` | 已核对频道、视频 ID、可见性及描述源哈希的元数据关联 |
| `pre_existing_video_associations_verified` | 上述记录中的频道既有视频 |
| `new_uploads_completed_this_batch` | 本轮新增且已确认完成的上传；目前为 0 |
| `youtube_uploads_recorded` | 保留的兼容字段，与本轮新增完成数一致 |
| `playback_verifications_recorded` | 单独的线上播放核验；目前为 0 |
| `youtube_caption_verifications_recorded` | 单独的线上字幕核验；目前为 0 |

这些数字仅对应本库已有来源映射，不能作为频道视频总数。实际回读应保留证据来源、收据哈希和覆盖范围，不能靠手改字段升级状态。

## 维护变更

提交包括本次公开目录与文本的差异，注明来源与实际核验范围。涉及身份对齐、事件归并、版本选择、字幕修订或线上发布变化时，应留下可复查说明。不要只改项目页而不更新对应结构化记录；生成页面应与同一版目录一致。
