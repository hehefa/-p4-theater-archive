# P4 公开候选档案 / P4 Theater Archive

从 [项目与素材目录](INDEX.md) 浏览编号、来源关系和待核实状态。这里的候选目录帮助继续核对材料；登记在目录中不表示可以公开上传。

P4始于北京，以表演、摄影、影像和写作展开现场实践。[认识P4](https://p4theater.cn/about/p4-theater/) · [当前官网](https://p4theater.cn/) · [公共档案](https://a.p4theater.cn/) · [研究文献库](https://b.p4theater.cn/)。

## 从这里开始

- **认识项目：** [官方项目索引](registry/README.md)，从项目原文进入P4。
- **读一段材料：** [玻璃动物园阅读样板](projects/P4-P000013/index.md) · [当前公开字幕](reading/captions.md)。
- **下载已完成资料：** [作品发行版字幕](published/captions.md) · [公开文稿与研究](published/materials.md)，逐项保留出处、原文链接和版本。
- **查来源与版本：** [档案总目录](INDEX.md) · [身份对照](docs/身份对照.md) · [已有视频关联](publications/README.md)。
- **补充与协作：** [增补指南](CONTRIBUTING.md) · [Mac/PC协作规则](docs/跨端协作.md) · [本轮交接](coordination/current-batch.json)。

公开字幕可在本地按关键词查找，结果保留字幕版本、cue、源零点时间和原文链接：

```sh
python -X utf8 scripts/public_reading.py search --root . --query "剧本"
```

见 [阅读与检索](docs/阅读与检索.md)、[既有成果接入](docs/既有成果接入.md)。本仓负责公开目录与文本版本，[P4 Archive Toolkit](https://github.com/hehefa/p4-archive-toolkit)提供本地文献、来源和修订工具。

## 当前公开范围

私有主目录保留首轮盘点的 **1,740 个物理视频文件**及永久编号。当前公开投影保留 **1,445 个候选视频文件、16 个候选项目、18 个来源集合**；295 项家庭混合候选或单独官网关联待核实材料已移出当前公开目录。它们不是全部已确认为家庭录像，原文件也没有被搬动或删除。

[官方公开项目注册表](registry/README.md) 另存中英文官网共同列出的 **34 条项目条目**。它与本批本地视频目录用途不同，不能相加，也不能作为 P4 全部历史项目的总数。

原片候选目录的字幕正文保留 **3 份 SRT、1 个来源**：P4-V001069 / IMG_3556.MOV 的原语、英文、中英双语机器稿。官方 A 站列出相同原片完整 SHA-256，B 主档案正文提供玻璃动物园围桌读本的实质上下文；见 [字幕目录](captions/README.md) 和该素材的官方证据。它们尚未逐句听校。

[已完成资料包](published/README.md) 另按准确发行版收录官网已公开字幕、文稿和研究，以及有来源对应的完整字幕成品。它使用官网材料ID、YouTube ID及版本SHA，不推定与原片候选相同，不把这些数量并入原片盘点。

该视频的三版独立命名字幕已在既有视频上发布，观看端菜单可选择；仅新中文在 00:12 实际渲染得到抽验，英文、双语及首中尾样本尚未完成。原有 3,126 条平台字幕未覆盖，新原语稿为 1,728 条；旧版以 [P4-S001760 元数据](evidence/P4-S001760-platform-version-metadata.json) 单独登记，原件留私有端，本轮不公开第 4 份正文。旧名中的 machine reviewed 不构成人工听校证明。

先前公开的另外 96 份字幕已从当前树移出，私有主目录保留原版本和哈希，等待官网逐项证据；这不把它们判成家庭材料。当前树移除不等于抹除既有 Git 提交历史。

## 关联与核验分别记录

当前有 [17 条频道既有公开视频关联](publications/README.md)：其中 16 条是 Studio 描述源 SHA 映射，另 1 条为上述官方来源及字幕操作观察。它们都不是本轮新增视频上传；16 条平台映射本身也不证明项目内容相关，不能作为其他素材的公开白名单。

现有 **8 个逐文件官方正证**，其余 1,437 个非禁发候选仍待来源核对；新增 7 项只补安全元数据，不开放正文或新上传。510 的 5 段属于 P4 实践讨论证据，不据此称为正式剧目。跨项目、BODY 关键词及外部参考材料仍按候选处理，见 [复核摘要](evidence/cross-project-review-summary.json)。没有整目录放行。

[目录汇总](catalog/summary.json) 分别记录私有盘点、公开候选、官方来源关联、原片校验、字幕版本和平台回读。家庭材料禁止发布；家庭混合候选必须逐项分离，不能因一个文件夹属于项目就整批公开。新视频上传或字幕正文公开须同时通过官方来源关联与家庭排除检查。

编号不因公开范围收缩而销号。完整来源位置、被排除记录和版本历史保留在私有端；公开文件只保留符合当前范围的引用闭包。同一路径增量导入沿用编号；移动或改名须先迁移私有路径登记，导入器不会自动识别移动。

原始视频仍需独立备份，GitHub 目录与 YouTube 转码副本都不能替代原片。公开可访问不代表所有材料采用统一开放许可；权利、内容归属和核验范围按条目记录。
